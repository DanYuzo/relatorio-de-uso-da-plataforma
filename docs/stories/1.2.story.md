# Story 1.2: Client API + Adapter Layer

## Story Statement

**Como** operador do dashboard Prosperus,
**eu quero** que os dados da CursoEduca sejam buscados automaticamente e transformados no formato que o dashboard já entende,
**para que** o pipeline de métricas e exportação funcione identicamente com dados da API ou CSV.

## Acceptance Criteria

- [ ] **AC1:** `cursEducaClient.ts` expõe métodos `fetchMembers()`, `fetchAccessReports(dateRange?)`, `fetchProgressReports(dateRange?)`, `fetchEnrollments(dateRange?)` que chamam o proxy da Story 1.1
- [ ] **AC2:** Cada método pagina automaticamente até `hasMore === false`, agregando todos os resultados
- [ ] **AC3:** Cada método aceita um callback `onProgress(message: string, percent: number)` chamado a cada página
- [ ] **AC4:** `apiAdapter.ts` transforma dados da API nos tipos CSV existentes: `AcessoRow[]`, `ConclusaoRow[]`, `ProgressoRow[]`, `UltimoAcessoRow[]`
- [ ] **AC5:** `buildParsedDatasetFromApi()` recebe `ReferenciaRow[]` (do CSV upload) como primeiro parâmetro e usa `buildEmailToEmpresaMap()` + `enrichWithEmpresa()` de `csvParser.ts` para enriquecer os dados — NUNCA usa grupos da API como fonte de empresa
- [ ] **AC6:** `ParsedDataset` gerado pelo adapter é estruturalmente compatível com o gerado por `processDataset()` — `computeMetrics()` funciona sem modificação
- [ ] **AC7:** `dataSourceOrchestrator.ts` expõe `loadData(source, ...)` que retorna `ParsedDataset` independente da fonte
- [ ] **AC8:** Erros de rede, timeouts e respostas malformadas da API são tratados gracefully — o client lança erros com mensagens descritivas sem crashar a aplicação
- [ ] **AC9:** Testes unitários em `tests/unit/apiAdapter.test.ts` validam todos os transformadores com dados mock, incluindo edge cases (campos nulos, arrays vazios)
- [ ] **AC10:** Lint e typecheck passam sem erros

### Decisão de Descope: `fetchGroups()` Removido

O épico lista `fetchGroups()` no escopo original do client. Este método foi **intencionalmente removido** porque:
- Os grupos de acesso na CursoEduca estão mal configurados (contêm pessoas erradas)

- Buscar grupos seria desperdício de chamadas de API sem utilidade no pipeline

Se no futuro os grupos forem corrigidos na CursoEduca, o método pode ser adicionado ao client sem impacto na arquitetura.

```typescript
function transformAccessToAcessos(reports: ApiAccessReport[]): AcessoRow[] {

    Nome: r.memberName ?? '',
    Email: r.memberEmail ?? '',
    Data: r.createdAt,  // ISO 8601 — safeParseDate() já trata
```

#### 3. `ApiProgressReport[]` → `ConclusaoRow[]`

```typescript
function transformProgressToConclusoes(reports: ApiProgressReport[]): ConclusaoRow[] {
  return reports.map(r => ({
    Nome: r.member.name ?? '',
    Email: r.member.email,
    'Conteúdo': r.lesson?.section?.content?.title ?? '',
    'Módulo': r.lesson?.section?.title ?? '',
    'Nome da aula': r.lesson?.title ?? '',
    'Data de conclusão': r.finishedAt,
  }));
```

#### 4. `ApiEnrollment[]` → `ProgressoRow[]`

```typescript
function transformEnrollmentsToProgresso(enrollments: ApiEnrollment[]): ProgressoRow[] {
  return enrollments.map(e => ({
    Nome: e.member.name,
    Email: e.member.email,
    'Situação do membro': mapSituationId(e.situationId),
    Progresso: `${e.progress}%`,
    'Conteúdo': e.content.title,  // Campo fixo — NÃO precisa de pickContentKey()

}
```

**Nota:** `situationId` precisa ser mapeado para texto. Valores prováveis: 1=Ativo, 2=Inativo, 3=Cancelado. Usar fallback defensivo.

#### 5. `buildParsedDatasetFromApi()` — Composição Final

```typescript
function buildParsedDatasetFromApi(
  referencia: ReferenciaRow[],           // do CSV upload
  members: ApiMember[],
  accessReports: ApiAccessReport[],
  progressReports: ApiProgressReport[],
  enrollments: ApiEnrollment[],
): ParsedDataset {
  // Transformar dados da API
  const acessos = transformAccessToAcessos(accessReports);
  const conclusoes = transformProgressToConclusoes(progressReports);
  const progresso = transformEnrollmentsToProgresso(enrollments);
  const ultimoAcesso = transformMembersToUltimoAcesso(members);

  // Reutilizar pipeline existente para enriquecer com Empresa
  const emailToEmpresa = buildEmailToEmpresaMap(referencia);
  enrichWithEmpresa(acessos, emailToEmpresa);
  enrichWithEmpresa(conclusoes, emailToEmpresa);
  enrichWithEmpresa(progresso, emailToEmpresa);
  enrichWithEmpresa(ultimoAcesso, emailToEmpresa);

  const empresasUnicas = getUniqueEmpresas(referencia);

  return { referencia, acessos, conclusoes, progresso, ultimoAcesso, empresasUnicas };
}
```

### Client HTTP — Paginação

```typescript
async function fetchAllPages<T>(
  endpoint: string,
  service: 'members' | 'contents',
  params: Record<string, string | number>,
  onProgress?: (msg: string, pct: number) => void,
): Promise<T[]> {
  const allData: T[] = [];
  let offset = 0;
  const limit = params.limit ?? 100;
  let hasMore = true;
  let totalCount = 0;

  while (hasMore) {
    const response = await fetch('/.netlify/functions/api-proxy', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ service, endpoint, params: { ...params, limit, offset } }),
    });

    const json: ApiPaginatedResponse<T> = await response.json();
    allData.push(...json.data);

    totalCount = json.metadata.totalCount;
    hasMore = json.metadata.hasMore;
    offset += limit;

    if (onProgress) {
      const pct = Math.min(100, Math.round((allData.length / totalCount) * 100));
      onProgress(`Buscando dados... ${allData.length}/${totalCount}`, pct);
    }
  }

  return allData;
}
```

### Orchestrator — Interface Unificada

```typescript
type DataSource = 'api' | 'csv';

interface ApiLoadConfig {
  referencia: ReferenciaRow[];  // sempre do CSV
  dateRange?: { start: string; end: string };
  onProgress?: (msg: string, pct: number) => void;
}

async function loadData(
  source: DataSource,
  config: ApiLoadConfig | { uploadedFiles: Record<string, unknown[]> },
): Promise<ParsedDataset> {
  if (source === 'csv') {
    return processDataset((config as any).uploadedFiles);
  }
  // source === 'api'
  const apiConfig = config as ApiLoadConfig;
  const members = await fetchMembers(apiConfig.onProgress);
  const access = await fetchAccessReports(apiConfig.dateRange, apiConfig.onProgress);
  const progress = await fetchProgressReports(apiConfig.dateRange, apiConfig.onProgress);
  const enrollments = await fetchEnrollments(apiConfig.dateRange, apiConfig.onProgress);
  return buildParsedDatasetFromApi(apiConfig.referencia, members, access, progress, enrollments);
}
```

### Datas da API

Datas da CursoEduca vêm em ISO 8601 (ex: `2026-03-15T14:30:00.000Z`). A função `safeParseDate()` em `src/utils/dateHelpers.ts` (L16-24) já trata ISO 8601 corretamente. Os filtros de data da API usam parâmetros:
- Access: `createdSince`, `createdUntil`
- Progress: `finishedSince`, `finishedUntil`
