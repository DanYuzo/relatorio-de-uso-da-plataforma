# Story 1.3: UI — Modo Dual (API Híbrido + CSV)

## Story Statement

**Como** operador do dashboard Prosperus,
**eu quero** alternar entre buscar dados automaticamente da API (com referencia.csv manual) ou fazer upload completo dos 5 CSVs,
**para que** eu tenha flexibilidade e um fallback confiável caso a API esteja indisponível.

## Acceptance Criteria

- [ ] **AC1:** Toggle visual na tela de upload permite alternar entre "Conexão API" e "Upload Manual (CSV)"
- [ ] **AC2:** Modo API: exibe zona de upload APENAS para `referencia.csv` + botão "Buscar Dados da Plataforma"
- [ ] **AC3:** Modo API: após upload do referencia.csv e clique em "Buscar Dados", barra de progresso mostra andamento real do fetch (mensagem + percentual)
- [ ] **AC4:** Modo API: dashboard renderiza corretamente com dados híbridos (referencia do CSV + atividade da API)
- [ ] **AC5:** Modo CSV: funciona identicamente ao sistema atual — upload dos 5 arquivos, processamento, dashboard, e export HTML/ZIP (ZERO regressão em todo o fluxo)
- [ ] **AC6:** Export HTML/ZIP no modo API produz dashboards idênticos ao modo CSV para os mesmos dados
- [ ] **AC7:** Erros de conexão com a API são exibidos com mensagem clara e opção de retry
- [ ] **AC8:** Design segue o branding Prosperus Club (Midnight Blue #031A2B, Gold #FFDA71, fonte Manrope)
- [ ] **AC9:** Layout responsivo funciona em mobile e desktop
- [ ] **AC10:** Na primeira carga (sem interação com toggle), a tela exibe o modo CSV com experiência idêntica à versão anterior — nenhuma mudança visual a menos que o toggle seja usado
- [ ] **AC11:** `handleReset` a partir do modo API retorna à tela de upload em estado limpo (ambos os modos resetados)
- [ ] **AC12:** Lint e typecheck passam sem erros

### DataSourceSelector — Design

Toggle estilo "tab" com duas opções:
- **Conexão API** (icon: Wifi ou Zap) — modo híbrido
- **Upload Manual** (icon: Upload) — modo CSV completo

Usar estilo similar ao `PeriodFilter.tsx` que já tem botões toggle na aplicação.

### ApiConnectionPanel — Design

Composto por:
1. **Upload de referencia.csv** — zona de drop/click similar à existente mas APENAS para 1 arquivo
2. **Status de validação** — checkmark quando referencia.csv está válido
3. **Botão "Buscar Dados da Plataforma"** — habilitado somente quando referencia.csv foi uploaded e validado
4. **Barra de progresso** — mostra andamento do fetch em tempo real
5. **Status de erro** — mensagem de erro + botão retry se falhar

### Fluxo do Modo API

```
1. Usuário seleciona "Conexão API"
2. Faz upload de referencia.csv
3. Sistema valida referencia.csv (mesma validação existente)
4. Botão "Buscar Dados" fica habilitado
5. Clique → ProcessingScreen com progresso real da API
6. Fetch completo → setData(parsedDataset) → Dashboard
```

### Fluxo do Modo CSV (Inalterado)

```
1. Usuário seleciona "Upload Manual" (ou mantém default)
2. Upload dos 5 CSVs (fluxo existente — nada muda)
3. Clique "Processar" → ProcessingScreen → Dashboard
```
