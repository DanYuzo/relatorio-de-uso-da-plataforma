# Story 1.1: Backend Proxy + Tipos da API CursoEduca

## Story Statement

**Como** operador do dashboard Prosperus,
**eu quero** que a aplicação se comunique com a API da CursoEduca de forma segura,
**para que** os dados de atividade sejam buscados automaticamente sem expor credenciais no navegador.

## Acceptance Criteria

- [ ] **AC1:** Netlify Function `api-proxy` responde em `/.netlify/functions/api-proxy` e aceita requisições POST com body `{ service, endpoint, params }`
- [ ] **AC2:** O proxy lê `CURSEDUCA_API_KEY` exclusivamente de `process.env` — a chave NUNCA aparece no código-fonte ou no bundle client-side
- [ ] **AC3:** Requisições com `service: 'members'` são repassadas para `https://prof.curseduca.pro` e com `service: 'contents'` para `https://clas.curseduca.pro`
- [ ] **AC4:** Erros da API CursoEduca (4xx, 5xx) são capturados e retornados ao client com status code e mensagem adequados
- [ ] **AC5:** Requisições com `service` inválido retornam 400 Bad Request
- [ ] **AC6:** Requisições com método diferente de POST retornam 405 Method Not Allowed
- [ ] **AC7:** O parâmetro `endpoint` é validado contra uma allowlist de paths permitidos (`/members`, `/groups`, `/groups/{id}/members`, `/reports/access`, `/reports/progress`, `/api/reports/enrollments`, `/api/reports/contents`) — paths fora da lista retornam 403 Forbidden
- [ ] **AC8:** Header `Access-Control-Allow-Origin` é restrito ao domínio de produção (não usa `*`); em dev local, permite `localhost`
- [ ] **AC9:** Interfaces TypeScript em `src/types/api.ts` cobrem: `ApiMember`, `ApiGroup`, `ApiAccessReport`, `ApiProgressReport`, `ApiEnrollment`, `ApiPaginatedResponse<T>`
- [ ] **AC10:** `netlify.toml` inclui seção `[functions]` apontando para `netlify/functions`
- [ ] **AC11:** `@netlify/functions` está adicionado como devDependency no `package.json`
- [ ] **AC12:** Lint (`npm run lint`) e typecheck (`tsc -b`) passam sem erros

## Dev Notes

### Arquitetura do Proxy

O proxy é uma camada fina — recebe a requisição do frontend, injeta o header `api_key`, repassa para o serviço correto da CursoEduca e retorna a resposta. **NÃO** acumula paginação (1 chamada = 1 página). A paginação será orquestrada pelo client (Story 1.2).

```
Frontend → POST /.netlify/functions/api-proxy → CursoEduca API → Response
             { service, endpoint, params }         api_key header
```

### Base URLs dos Serviços

| Service | Base URL |
|---------|----------|
| `members` | `https://prof.curseduca.pro` |
| `contents` | `https://clas.curseduca.pro` |

### Autenticação da API

- Header: `api_key: {valor}` (NÃO é Bearer token, é header customizado)
- Variável de ambiente: `CURSEDUCA_API_KEY`
- Para dev local: `netlify dev` injeta env vars do `.env` ou do painel Netlify

### Formato de Requisição do Proxy

```typescript
// Body da requisição POST ao proxy
interface ApiProxyRequest {
  service: 'members' | 'contents';
  endpoint: string;       // ex: '/members', '/reports/access', '/api/reports/enrollments'
  params?: Record<string, string | number>;  // query params: limit, offset, etc.
}
```

```typescript
interface ApiPaginatedResponse<T> {

interface ApiMember {

  document?: { type?: string; value?: string };

  slug?: string;
  groups?: ApiMemberGroup[];

  updatedAt?: string;

  id: number;
  uuid?: string;
  name: string;
  expiresAt?: string;
  isActive?: boolean;
}

// GET /groups
interface ApiGroup {
  id: number;
  uuid: string;
  name: string;
  description?: string;
  membersCount?: number;
  isActive?: boolean;
  expirationType?: string;
  expiresAt?: string;
  expirationInterval?: number;
}

interface ApiAccessReport {
  id?: number;
  memberName?: string;
  memberEmail?: string;
  createdAt: string;   // ISO 8601
}

// GET /reports/progress
interface ApiProgressReport {
  id: number;
  finishedAt: string;  // ISO 8601
  lesson: {
    id: number;
    title: string;
    section?: {
      id: number;
      title: string;
      content?: {
        id: number;
        title: string;
        slug?: string;
      };
    };
  };
  member: {
    id: number;
    email: string;
    name?: string;
  };
  enrollment?: {
    id: number;
    progress: number;
    group?: {
      id: number;
      uuid?: string;
      name?: string;
    };
  };
}

// GET /api/reports/enrollments
interface ApiEnrollment {
  id: number;
  content: {
    id: number;
    title: string;
    slug?: string;
  };
  startedAt?: string;
  finishedAt?: string;
  member: {
    id: number;
    name: string;
    email: string;
    slug?: string;
    groupIds?: number[];
  };
  situationId?: number;
  progress: number;     // 0-100
  expiresAt?: string;
  expirationEnabled?: boolean;
  integration?: string;
}
```
